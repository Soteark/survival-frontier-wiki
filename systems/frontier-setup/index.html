    Frontier Setup¶

    When you start a new world, the host picks which Survival Frontier features it uses. Turn off what you don't want, for example fishing or the Scannerbot, and the rest of the mod works as usual. The host can change most of them later.

    At a glance

    • The window opens for the host on a new world's first spawn, before the intro.
    • Features are in groups, two columns, one small ON / OFF switch each, plus All On, Close and Start.
    • Type /frontier any time to open the window again. The host changes features and presses Apply; everyone else can look.
    • Land Clearing can only be chosen before Start: it changes the terrain. It shows (set at world start) after that.
    • Worlds made before the setup existed have everything on.

    The window¶

    • A feature that needs one that's off shows (needs ...) and can't be switched on. Turning off Contracts also turns off the Traveling Trader, and with it Elite Creatures and every Trader Blueprint. Turn Contracts back on and they come back as you left them.
    • After Start, everyone sees a chat line: "host finished the Frontier Setup. Off in this world: ...".
    • If the host closes the window without pressing Start, the world waits: contracts, the trader, Backpack Expansion loot and the starting Frontier recipes all hold off until the setup is finished. The host types /frontier to open the window again.

    Changing features later¶

    • The host types /frontier, flips switches and presses Apply. A changed switch shows a yellow *, and the status line counts the changes not applied yet.
    • Everyone sees a chat line: "host changed the Frontier features: Fishing on, Frontier Cooking off."
    • Some switches (Frontier Cooking, Craftbot Cancel Buttons, Modded Craftbot Recipes) change Craftbot or Cookbot windows: they finish the next time the world loads.
    • The Scannerbot switch and /scannerbot on|off are the same switch.

    /frontier¶

    Who Before Start After Start
    Host opens the setup window again opens the window to change features
    Everyone else "The host hasn't finished the Frontier Setup yet." opens the window to look (switches are grey)

    What "off" means¶

    Turning a feature off stops anything new from it: its recipes aren't unlocked, the trader doesn't sell its blueprints, and it doesn't turn up in loot or contracts. Recipes the party already learned stay learned, and anything already built keeps working. Turning a feature on later unlocks its starting recipes and puts its blueprints back in the shop.

    Contracts and Trading¶

    Switch Turning it off
    Contracts No new contracts are posted and the Outpost Board isn't sold. Also turns off the Traveling Trader. See Contract Board.
    Traveling Trader Needs Contracts. The trader never camps and sells nothing. Also turns off Elite Creatures and every Trader Blueprint. See Traveling Trader.
    Elite Creatures Needs the Traveling Trader. The trader never offers to stir up the robots, and no new elites appear. See Elite Creatures.
    Backpack Expansions None in loot, contract rewards, the trader's gear, Sunken Crates or elite drops. See Backpack Expansions.

    Survival and World¶

    Switch Turning it off
    Fishing No Fishing Rod or bait recipes, no Carbon Rod blueprint, no Catch Orders, and elites drop no fishing gear. See Fishing.
    Frontier Cooking No Campfire or Frontier dishes; the Cookbot keeps its vanilla recipes and window. The trader's dish recipes are hidden and contracts don't pay in food. See Frontier Kitchen.
    Land Clearing Set at world start only. No Scythe recipe, and plants can't be cleared. See Land Clearing.
    Grip Pad No Grip Pad recipe at the Craftbot. Pads already built keep working. See Grip Pad.
    Mower Blade No Mower Blade recipe at the Craftbot. Blades already built keep working.
    Scannerbot The vanilla flying missile drone is off. Same switch as /scannerbot. See Scannerbot.

    Interface¶

    Switch Turning it off
    Milestone News No chat news when the party reaches a milestone. The Milestone Log still counts.
    Craftbot Cancel Buttons No cancel buttons under the Craftbot window (after the world loads again).
    Modded Craftbot Recipes Other mods' Craftbot recipes aren't unlocked for you.
    Bug Reports Always on: /bugreport has no switch.

    Trader Blueprints¶

    All of these need the Traveling Trader. Turning one off hides its blueprints in the shop.

    Switch Blueprints
    Map Table The Map Table. The map still fills in while you explore, so a table bought later is up to date.
    Remote Control The Remote Controller and Remote Camera. See Remote Control.
    Wireless Link The Transmitter and Receiver.
    Solar Power Solar Panel, Charge Controller, Inverter, Mega Battery Bank, Mega Battery, Floodlight and Light Sensor. See Power.
    Teleport Pads The Teleport Pad. Also needs Solar Power: a pad runs off an Inverter.
    Scrapper The Scrapper.
    Pipe Parts The Pipe Coupler and Carbon Pipes.
    Gyro and Signal Parts Gyro Flywheels, the signal parts and the Throttle Thruster.

    Tools and Base¶

    Switch Turning it off
    Rechargeable Batteries The Rechargeable Battery and Charger blueprints are hidden, and Electric Engines stop drawing Rechargeables from a Battery Container. See Power.
    Base Logistics No Trash Can recipe, and the Item Sorter, Sorting Chest, Storage Terminal and Container Sensor blueprints are hidden. See Base Logistics.
    Grapple Gun No Grapple Gun recipe at the Craftbot.
    Ziplines No Zipline Anchor or Trolley recipe at the Craftbot.
    Spotlight No Spotlight recipe at the Craftbot.
    Frontier Plating No Frontier Plating recipe at the Craftbot.
